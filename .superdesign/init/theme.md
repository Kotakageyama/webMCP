# Theme

## Compact token summary

- Font: `Arial, Helvetica, sans-serif`.
- Dark canvas: `--bg #0a0a0a`, `--elev #11110f`; subtly dotted background.
- Panels: dark translucent gradients; `--border rgba(255,255,255,.1)`; radius 18px.
- Text: `--text #f5f5ef`, `--muted #9a9a93`.
- Accents: `--gold #d0a46a` for decisions, `--success #78c69b`, `--danger #ef877c`.
- Responsive breakpoint: `960px`; Security Lab swaps its two-column cards to one column.

## Raw sources

Global tokens and base typography are in `app/styles.css`; Security Lab card and responsive rules are in `app/security-lab/security.css`.
