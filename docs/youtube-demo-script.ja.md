# TaskSurface — 3 分 YouTube デモ台本（日本語版）

**目標時間:** 2 分 35 秒〜2 分 50 秒

**言語:** 日本語ナレーション（必要に応じて日本語字幕）

**収録 URL:** https://tasksurface-nlgt6zklja-an.a.run.app

**中心メッセージ:** WebMCP はエージェントにツールを呼ばせるだけでは不十分です。人が作業を監督・修正・承認できる、集中した共有画面を提供するべきです。

## 収録前

1. デスクトップ幅でライブアプリを開き、`Order #TS-1042` が表示されることを確認します。
2. 実際の WebMCP 操作を収録する場合は、ChatGPT デスクトップアプリの内蔵ブラウザ、または `chrome://flags/#enable-webmcp-testing` を有効にした Chrome を使います。視聴者の理解に役立つときだけエージェント・ブラウザのツール表示を出し、TaskSurface UI を主役にします。
3. 通知をオフにし、クリーンなブラウザプロファイルを使います。
4. 1440p または 1080p で収録します。著作権のある音楽や第三者ブランドの映像は使いません。
5. `.env`、Cloud Console のシークレット値、データベース URL、個人のブラウザタブを映さないでください。
